# PS99 / Pinata Fiesta

Два скрипта: авто-прогресс основного PS99 и фармер ивента Pinata Fiesta.
Сборки упакованы, но распаковываются на клиенте в байт-в-байт исходник,
который тестировался в живой игре.

| Файл | Что делает |
|---|---|
| `ps99.lua` | Авто-прогресс: ранги, миры, экономика, оптимизация клиента. По достижении заданного ранга сам переходит в Fiesta и передаёт ей управление |
| `fiesta.lua` | Фармер ивента: рейды по мейзу, Pinata-челленджи, апгрейды, гифты, бустеры |

## Запуск

Одна строка — она поднимает всю связку:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/fornamess/puzo/main/ps99.lua"))()
```

Фиеста подтягивается по URL автоматически, отдельно запускать её не нужно.
Только фиесту (если аккаунт уже в ивенте):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/fornamess/puzo/main/fiesta.lua"))()
```

## Настройка

Конфиг задаётся **до** loadstring, любое поле можно переопределить:

```lua
getgenv().PS99_CONFIG = {
    FiestaAfterRank = 10,   -- с какого ранга уходить в Fiesta; 0 = не уходить
    FiestaHandoff   = true, -- false = фармить только ранги
}
loadstring(game:HttpGet("https://raw.githubusercontent.com/fornamess/puzo/main/ps99.lua"))()
```

Неизвестное имя поля или неверный тип значения отклоняются с записью в
`getgenv().PS99_CONFIG_APPLIED`, а не ломают запуск молча.

Настройки самого фармера — через `getgenv().PINATA_FIESTA_CONFIG`:

```lua
getgenv().PINATA_FIESTA_CONFIG = {
    ChallengeChain         = true, -- цепочка Pinata-челленджей вместо рейдов
    MaxMazeBoostersPerPass = 4,    -- бустеры: всегда самый высокий тир
    BoosterRefreshSeconds  = 45,   -- дожигать, только когда таймер на исходе
    FastRecycle            = true, -- рейд→рейд без захода в лобби
}
```

Горячие клавиши фармера: `RightShift` — HUD, `End` — остановка.

## Как ведёт себя связка

1. Ранг ниже порога — обычный авто-прогресс.
2. Ранг достигнут — маршрут в мир 4 (Pinata Fiesta) и передача управления:
   farm-тик и игровые джобы останавливаются, работают только оптимизации
   клиента и супервизор фармера.
3. Фармер умер или сервер мигрировал — супервизор поднимает его заново.
4. Клиент завис на экране загрузки (модули игры не инициализируются) — через
   120 секунд выполняется переподключение к тому же плейсу, максимум 3 попытки
   за 15 минут. Дальше сессия честно умирает, чтобы лаунчер перезапустил процесс.

`FiestaScriptURL` кэшируется в `PS99/fiesta/PinataFiesta_AutoFarm.lua`: без сети
запускается последняя рабочая копия, а кэш перезаписывается только исходником,
который скомпилировался. Обновление всей фермы — один push в этот репозиторий.
